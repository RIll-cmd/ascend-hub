# Ascend agent entry point

At the start of a new task or after switching coding agents, read `ASCEND_HANDOFF.md` in this repository. It is the shared continuity document for Hub, Core, and Vision.

Confirm the intended repository/worktree using Git status and the handoff. For running-app issues, verify the installed desktop profile's checkout. Read applicable local instructions and the project README before editing.

Before handing work to another agent, update the handoff's Current session with the objective, exact checkout, changed files, validation results, outstanding issues, next action, and commit/push status. Preserve unrelated work and keep credentials and private runtime data out of documentation.
