# Design references

These files document the Hub's design system and preserve its original exports:

- `design-system.md`: design-system notes.
- `figma-export.json`: reference design export.
- `tokens.json`: reference token definitions.
- `theme.css` and `variables.css`: reference styles; their relative import remains intact.

Runtime styling lives in `app/globals.css` and the application components. Runtime assets live in `public/`. Local QA screenshots, crops, and the duplicate shelf source model are retained in ignored `scratch/design/`, not published to GitHub.

The standalone TV reference project is preserved under `vendor/zzz-tv-reference/`. The authoritative Status Shelf architecture remains at the repository root in `future ai implementation.md`.
